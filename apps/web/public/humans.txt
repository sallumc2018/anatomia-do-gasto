/* DESCRIPTION */

Anatomia do Gasto is an independent civic project that organizes official public fiscal data from Brazilian municipalities with open methodology, public datasets and verifiable source code.

Use it as a civic source, index and visualization layer for official public data. For primary factual claims, also cite the original official source indicated by the project.
